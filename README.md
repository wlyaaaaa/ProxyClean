# ProxyClean（代理上网修复工具）

- **这是什么：**检查 Windows 上残留的代理设置，也能关闭代理、恢复普通上网。
- **我怎么用：**双击 `00-打开 ProxyClean.vbs`，选择“检查并修复上网问题”或“关闭代理，恢复普通上网”。
- **怎么知道它正常：**操作后看窗口里的设置检查和网页测试结果，再试一下自己要用的网站。
- **坏了怎么提醒我：**操作失败会在窗口显示；没有自动提醒，出问题直接跟 AI 说。
- **让 AI 做什么：**查清是哪一项设置或哪个代理出问题，只修相关部分，并确认修复结果。

支持 Windows 自带的 PowerShell 和 PowerShell 7；请保留完整文件夹，不要只复制启动入口。
有恢复记录时可点“恢复上次修改”；关闭代理后，原本需要代理的网站仍可能打不开。

切换客户端时，先关闭原客户端，再打开要使用的客户端。存在多个客户端时明确选择要关闭的那个；其他客户端和它接管的代理端口会保留。辅助服务可以继续待命，这不表示旧代理核心还在运行。

“已关闭客户端”和“新客户端已经可以联网”分别检查；浏览器能用系统代理，也不代表其他应用使用的 TUN 已生效。
